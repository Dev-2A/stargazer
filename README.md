# 🌌 Stargazer

위치와 시간을 입력하면 그 시점의 하늘을 Three.js로 렌더링하는 인터랙티브 별자리 시뮬레이터.

## ✨ 주요 기능 (v0.1.0)

- 🌍 위치 입력 + 날짜·시간 슬라이더
- ✨ 3D 천구 — 별 크기는 등급, 색은 분광형으로 표현
- 🌟 88개 별자리 선 + 한국어 이름·신화
- 📸 현재 뷰 PNG 저장
- 💾 즐겨찾기 위치 IndexedDB 저장
- 📱 모바일 드로어 + 데스크탑 사이드바

## 🛠️ 기술 스택

- React 19 + Vite 7
- Tailwind CSS v4
- Three.js
- astronomy-engine
- HYG Star Catalog v3
- IndexedDB (idb)
- Zustand
- date-fns
